# Split Pay

**Reparte gastos compartidos en grupo — viaxes, pisos, ceas.**
Sen rexistro, sen servidor, e sen que os teus datos saian do teléfono se ti non queres.

## Funcionalidades

- Proxecto React + TypeScript que compila con Vite.

## Arrancar

```bash
npm install
npm run dev
```
